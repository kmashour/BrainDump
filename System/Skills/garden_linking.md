# SKILL: Digital Garden Pattern Mapping

This skill outlines how to identify and document cross-domain patterns inside the Digital Garden.

---

## 📋 Execution Steps
1. **Analyze Intersections:** When concepts cross multiple technology layers (e.g., how container runtime cgroup drivers interact with Linux kernel parameters), formulate a Pattern Note.
2. **Write Pattern Note:** Create or update the note in `Digital Garden/` using the pattern template.
3. **Cross-Link:** Link all participating concepts and point to hands-on project playbooks under `Projects/` where the pattern is verified.
