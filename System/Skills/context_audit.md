# SKILL: Reference Notes Context Auditing & Expansion

This skill outlines how to identify context gaps in the reference notes and expand secondary/tangent domains to ensure notes are self-contained.

---

## 📋 Execution Steps
1. **Identify Gaps:** Scan the Reference Note for external concepts that are mentioned but lack technical depth (e.g. systemd logs, OS swap params, reverse proxy headers).
2. **Add Context Volume:**
   - Expand the explanation of how the host system behaves.
   - Explain configuration parameters line-by-line (mechanical breakdown).
   - Ensure the user doesn't need to exit the vault to understand the underlying infrastructure behavior.
