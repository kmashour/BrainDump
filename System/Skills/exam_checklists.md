# SKILL: Certification Exam Checklist & Speed Extraction

This skill outlines how to build exam-focused checklists, terminal speed hacks, and rapid diagnostic workflows across certification paths (CKA, CKS, CKAD, KubeAstronaut, AWS SAA/SAP, Red Hat RHCSA, Azure AZ-104/305).

---

## 📋 Execution Steps
1. **Focus on Speed:** Capture command-line template generation flags (e.g. `--dry-run=client -o yaml`, AWS CLI query/filter flags, Linux quick one-liners).
2. **Speed Hacks:** Detail editor keystrokes (VIM/nano), alias mappings (`alias k=kubectl`, `alias tf=terraform`), and dynamic auto-completion scripts.
3. **Synthesis & Linkage:** Package exam notes into dedicated MOCs (`Reference Notes/0-Index - <CERT>.md`) and study spaces (`Projects/<CERT>/`), ensuring every checklist item links back to its Core Foundation Reference Note.
