# SKILL: Exam Checklist Extraction

This skill outlines how to build CKA and general certification exam checklists.

---

## 📋 Execution Steps
1. **Focus on Speed:** Capture YAML generation flags (`--dry-run=client -o yaml`).
2. **Speed Hacks:** Detail VIM keystrokes, alias mappings (`alias k=kubectl`), and dynamic auto-completion scripts.
3. **Troubleshooting Guides:** Package checklists into `Projects/CKA/` and organize by official exam domains (Cluster Maintenance, Troubleshooting, Storage, etc.).
