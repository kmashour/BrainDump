Title: ETIC, Platform & Cloud DevOps Senior Associate 
Job Summary
We are seeking to recruit a Platform & Cloud DevOps Senior Associate to join our team in Cairo. 
The successful candidate will have a minimum of 4+ years’ experience. They will be developing a reputation within the IT market, having worked on 4+ DevOps projects (at least two different DevOps solutions & at least 6 months on each project); providing valued thought leadership and opinion. They will be building a strong professional network and have a growing presence in the Engineering ecosystem.

You will be part of a team that reports to the Cloud Service Delivery Director and will be an integral part of the team based in Cairo, as well as those delivering client transformation programs across the PwC Global Network, including the UK, Germany, Middle East and Netherland.

Job Description
As a Platform & Cloud DevOps Senior Associate, you will be responsible for leading the design, implementation, and maintenance of secure and efficient DevOps activities in different cloud environments. You will work closely with SW development, AI, Data, operations, and security teams. Your expertise in Cloud technologies and DevOps best practices will be crucial in ensuring the stability, scalability, and security of our cloud-based environments.

Key Responsibilities
Mentorship and Team Development:
Mentor and coach less experienced engineers, fostering skill development in DevOps practices, cloud infrastructure, and automation. Provide technical guidance, encourage best practices, and promote continuous learning within the team.
Stakeholder Management and Communication:
Serve as the primary technical liaison for stakeholders, clearly communicating project progress, challenges, and risks. Ensure alignment between technical teams and business objectives and facilitate collaborative decision-making.
Design and Implement DevOps Pipelines:
Lead the design, implementation, and continuous optimization of CI/CD pipelines using tools like Azure DevOps, GitHub Actions, or cloud-native solutions (GCP, AWS or Azure experience) to automate the software development and deployment lifecycle.
Security Integration and Compliance:
Seamlessly integrate security tools and practices into the DevOps pipeline, ensuring continuous security testing, vulnerability scanning, and compliance with industry standards (e.g., GDPR, HIPAA, SOC 2). Utilize cloud-native security tools such as Google Cloud Security Command Center, AWS GuardDuty, or Azure Sentinel for proactive threat detection and incident response.
Solution Design and Requirements Analysis:
Collaborate with stakeholders and cross-functional teams to analyze business requirements, define cloud strategies, and design scalable, secure, and resilient solutions, preferably on Cloud platforms.
Infrastructure as Code (IaC) & Security as Code (SaC):
Implement and manage infrastructure using IaC tools like Terraform (preferred), CloudFormation (AWS), or ARM (Azure), with a strong focus on automating security controls and ensuring compliance throughout the development lifecycle.
Monitoring, Logging, and Performance Optimization:
Implement and manage monitoring and logging solutions using tools such as Google Cloud Operations Suite (preferred), AWS CloudWatch, Azure Monitor, or third-party platforms like Prometheus and Grafana to maintain high availability, performance, and security.
Containerization and Orchestration:
Design, deploy, and manage containerized applications using Docker and orchestrate them with Kubernetes or managed Kubernetes services like Google Kubernetes Engine (preferred), Amazon EKS, or Azure AKS. Ensure scalability, availability, and security of microservices architectures.
Required Skills and Experience:
Cloud Expertise:
Extensive hands-on experience of designing and implementation with at least one cloud provider—GCP, AWS, or Azure—including cloud services like Kubernetes, serverless functions, and managed databases.


DevOps Tools and Automation:
Strong proficiency in using CI/CD pipeline tools such as Azure DevOps, GitHub Actions, or cloud-native tools (GCP Cloud Build, AWS CodePipeline) for automating build, test, and deployment processes.
Security Tools and Practices:
Proficient in cloud-native security tools such as Google Cloud Security Command Center, AWS Security Hub, or Azure Security Center, with experience integrating security into the development pipeline and enforcing security best practices.
Infrastructure and Security as Code (IaC):
Experience with infrastructure provisioning and configuration using tools like Terraform (preferred), AWS CloudFormation, or Azure ARM templates, with a focus on automating security and compliance.
Monitoring and Logging Solutions:
Familiarity with monitoring and logging tools like Google Cloud Operations Suite, AWS CloudWatch, or Azure Monitor, as well as third-party tools like Prometheus, Grafana, and the ELK stack.
Containerization and Kubernetes:
In-depth experience with Docker and Kubernetes (GKE preferred, but EKS or AKS is acceptable) for deploying and managing containerized applications at scale.
Mentorship and Leadership:
Proven ability to mentor junior engineers, fostering their professional growth and helping them adopt best practices in cloud infrastructure and DevOps.
Stakeholder Communication and Management:
Strong communication skills for effectively managing stakeholder relationships, providing updates, and ensuring the alignment of technical solutions with business requirements.
