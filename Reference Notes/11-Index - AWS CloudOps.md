## 🏛️ Reference Modules & Frameworks

This index contains our AWS CloudOps and SysOps Engineering study modules, starting from logging and dashboard monitoring to systems manager automation, database scaling, backup lifecycles, governance, and hybrid networking.

- 📊 **[Module 11-1: CloudOps Monitoring, Logging & Dashboards](11-1_cloudops_monitoring_and_logging.md)**
  * Unified CloudWatch Agent deployment, system metric collections, custom metric filters, EventBridge rules, CloudTrail audits, and log group subscription filters.
- ⚙️ **[Module 11-2: Incident Response, Event Chaining & Remediation Automation](11-2_incident_response_and_ssm.md)**
  * Systems Manager (SSM) configurations (Run Command, Session Manager, Patch Manager), custom SSM Automation Runbooks, and auto-remediation triggers.
- ⚡ **[Module 11-3: Compute, Storage & Database Performance Optimization](11-3_performance_optimization.md)**
  * EC2 scaling performance, EBS storage class tuning (IOPS/throughput), S3 lifecycle bucket structures, and RDS Performance Insights & RDS Proxy session pools.
- 🛡️ **[Module 11-4: High Availability, Backup Lifecycle & Disaster Recovery](11-4_disaster_recovery_and_backups.md)**
  * Multi-AZ infrastructure deployments, ALB health check paths, Route 53 DNS failover rules, EBS snapshot policies, and AWS Backup central governance.
- 🔒 **[Module 11-5: Cloud Governance, Security Compliance & Auditing](11-5_governance_and_compliance.md)**
  * AWS Organizations policies, Service Control Policies (SCPs), AWS Config validation rules, Security Hub audits, GuardDuty threat detection, and IAM boundaries.
- 🚀 **[Module 11-6: Deployment Automation, CloudFormation & Hybrid Networks](11-6_automation_and_hybrid_networks.md)**
  * CloudFormation StackSets configurations, AWS CDK construct lifecycle, Transit Gateway pathing, and hybrid VPN connection diagnostics.
