## 🏛️ Reference Modules & Frameworks

This index contains our Amazon Web Services (AWS) cloud architecture modules, ranging from foundational Practitioner rules to SAA-level VPC networking and storage designs.

- 🔑 **[Module 3-1: AWS Global Infrastructure & Identity (IAM)](3-1_aws_global_infrastructure_and_iam.md)**
  * AWS global infrastructure (Regions, AZs, Edge Locations), IAM users/groups/roles, MFA, AWS KMS keys, AWS Organizations SCPs, Billing, and Support Plans.
- 🖥️ **[Module 3-2: AWS Compute & Storage Services](3-2_aws_compute_and_storage_services.md)**
  * Compute topologies (EC2 instance types, AMI, User Data), block storage (EBS gp2/gp3, EBS Provisioned IOPS), shared storage (EFS), and managed databases (RDS, DynamoDB).
- 🚦 **[Module 3-3: AWS Networking & Elastic Load Balancing](3-3_aws_networking_and_elastic_load_balancing.md)**
  * VPC infrastructure (Subnets, Route Tables, Internet Gateways, NAT Gateways), Security Groups vs. Network ACLs, Elastic Load Balancers (ALB, NLB), and Auto Scaling Groups.
- 🚀 **[Module 3-4: AWS Solution Architect Associate (SAA) Playbook](3-4_aws_solution_architect_associate_playbook.md)**
  * SAA study guidelines, cross-service architecture patterns, high availability database replicas, and practical lab scenario workflows.
